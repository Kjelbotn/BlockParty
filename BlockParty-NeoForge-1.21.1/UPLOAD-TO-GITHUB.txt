BLOCKPARTY 0.3.2-ALPHA — GITHUB UPDATE

This is an update for a repository that already has a working GitHub Actions workflow at .github/workflows/build.yml.

1. Extract this ZIP.
2. Open the ROOT of your GitHub repository (the same level as build.gradle).
3. Use Add file -> Upload files.
4. Upload the src folder and the root files in this ZIP. Do not upload an extra enclosing project folder.
5. Keep the existing .github/workflows/build.yml workflow; the update ZIP omits that hidden folder on purpose.
6. Commit changes. Actions should start a fresh build.
7. Download the artifact and verify it contains blockparty-0.3.2-alpha.jar.

If a path is nested under an extra BlockParty folder, cancel the upload and go back to the repository root before uploading.
