BLOCKPARTY 0.3.3-ALPHA - GITHUB UPDATE

For your existing BlockParty-Rebuild repository:
1. Open the repository root: the page where build.gradle and src/ are visible.
2. In this ZIP, use the src/ folder and upload it to that same repository root. Do not upload an outer project folder.
3. Also upload gradle.properties, README.md and CHANGELOG.md to the repository root.
4. Keep your already-working .github/workflows/build.yml. The GitHub Update ZIP intentionally omits the hidden .github directory.
5. Commit the changes to main. GitHub Actions should start automatically.

If the Actions artifact label still mentions 0.3.2, that is only the workflow's display name; the JAR produced by this source is blockparty-0.3.3-alpha.jar. You can rename the artifact label in the workflow later, but it is not required for compilation.

Before generating the new arena, back up the world and choose an empty area. Use /bp generate main (default 80x80) or /bp generate main 96.

Player progression is saved in blockparty-player-stats.properties in the world save folder. /bp leaderboard shows the top 10; /bp rank shows the player's points, rank and points remaining until the next rank.
