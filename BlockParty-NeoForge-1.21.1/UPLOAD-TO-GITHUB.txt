BLOCKPARTY 0.4.1-ALPHA — UPDATE EXISTING GITHUB REPOSITORY

1. Open the BlockParty-Rebuild repository root (where build.gradle and src/ are visible).
2. Upload the src/ folder and gradle.properties from this update ZIP to the same root.
3. Upload README.md and CHANGELOG.md if you want the docs updated.
4. Keep the existing .github/workflows/build.yml and Gradle wrapper files.
5. Commit to main and wait for GitHub Actions.
6. On a green build, download the artifact under Actions -> run -> Summary -> Artifacts.

Lobby use: right-click the turquoise BlockParty Join Game Nether Star to join.
Right-click the BlockParty Music Vote book to open the chat voting menu.
/bp join <id> remains as a fallback command.
